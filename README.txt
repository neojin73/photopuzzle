포토 퍼즐 (아이폰 · 안드로이드 공용 웹앱) 설치 방법
=====================================

이 폴더(index.html, manifest.json, sw.js, icons/)를 HTTPS 주소로 올린 뒤,
아이폰 Safari에서 열고 "홈 화면에 추가"를 하면 앱처럼 설치됩니다.

[방법 1] GitHub Pages (무료, 영구) - 추천
 1. github.com 가입/로그인 → 우측 상단 + → New repository
 2. 이름: photopuzzle, Public 선택 → Create repository
 3. "uploading an existing file" 클릭 → 이 폴더 안의 파일과 icons 폴더를 통째로 끌어다 놓기 → Commit changes
 4. Settings → Pages → Branch: main / (root) → Save
 5. 1~2분 후 https://<아이디>.github.io/photopuzzle/ 주소가 생깁니다.

[방법 2] Netlify Drop (가장 빠름)
 1. PC 브라우저에서 https://app.netlify.com/drop 접속
 2. 이 폴더를 통째로 끌어다 놓기 → 주소 생성
 3. 계속 쓰려면 무료 가입 후 사이트를 계정에 연결(claim)하세요.

[아이폰 15 설치]
 1. Safari로 위 주소 접속 (크롬 X, 반드시 Safari)
 2. 하단 공유 버튼(□↑) → "홈 화면에 추가" → 추가
 3. 홈 화면의 "포토퍼즐" 아이콘으로 실행 (전체화면, 한 번 실행 후 오프라인 가능)

[안드로이드 설치]
 1. 크롬(또는 삼성 인터넷)으로 같은 주소 접속
 2. 화면의 "앱 설치" 버튼을 누르거나, 크롬 메뉴(⋮) → "홈 화면에 추가"/"앱 설치"
 3. 홈 화면의 "포토퍼즐" 아이콘으로 실행
 - 이모티콘 "저장/공유" → "갤러리에 저장": 갤러리의 Download(다운로드) 앨범에 저장
 - "카톡·문자로 보내기": 공유 메뉴에서 카카오톡/메시지 선택
 - 폰의 뒤로가기 버튼/제스처로 이전 화면 이동

[사용법]
 - 사진 선택 → 퍼즐 크기(9~100조각) 선택 → 시작
 - 아래쪽 조각을 끌어 판 위 제자리에 놓으면 '딸깍' 하고 고정됩니다
 - 상단 버튼: 밑그림 켜기/끄기, 조각 다시 흩기, 눈 버튼(누르고 있으면 완성 사진 미리보기)
 - 완성 → "이모티콘 만들기" → 모양/필터/문구/꾸미기 선택 → "저장/공유"
 - 공유 메뉴에서 "이미지 저장"을 누르면 사진 앱에 저장되고, 카카오톡을 고르면 바로 전송됩니다
 - 공유 메뉴가 안 뜨면 이미지를 길게 눌러 "사진 앱에 저장"

※ 사진은 폰 안에서만 처리되며 어디에도 업로드되지 않습니다.

[AI 애니 수채화 필터]
 - 이모티콘 만들기 > 필터 > "🎨 애니 수채화 (AI)"
 - 처음 한 번만 AI 파일(약 16MB, ai 폴더)을 내려받고, 이후에는 오프라인에서도 동작합니다
 - 변환은 폰 안에서만 이뤄지며 사진은 외부로 전송되지 않습니다
 - GitHub에 올릴 때 ai 폴더도 꼭 함께 올리세요 (파일 5개)
 - 사용 모델: AnimeGANv3 (Hayao 스타일, TachibanaYoshino) — 비상업적 개인 사용 조건

[v6 새 기능]
 1. 이어하기: 앱을 닫거나 나가도 진행 상황이 자동 저장 → 처음 화면 "하던 퍼즐이 있어요"에서 이어하기
 2. 조각 회전 모드: 설정에서 켜면 조각이 돌아간 채 나옴 → 조각을 톡 누르면 90° 회전, 바르게 돌려야 맞춰짐
 3. 이모티콘 세트: 이모티콘 화면 > "세트로 만들기"에 문구를 쉼표로 입력(최대 6개) → 한 번에 여러 장 생성·공유
 4. AI 누끼(배경 제거): 이모티콘 모양 > "✂️ 누끼 오려내기 (AI)" → 사람/사물만 오려 흰 테두리 스티커로 (u2netp 모델, Apache-2.0)
 5. 어린이 모드: 설정에서 켜면 4~12조각, 판에 조각 모양 점선 표시, 가까이만 가져가도 쏙 맞춰지고 별 효과

[v7 반응형 화면]
 - 아이패드 · 안드로이드 태블릿 · 폰 가로 모드 · PC 브라우저 지원
 - 가로 화면: 왼쪽 퍼즐판 + 오른쪽 조각 보관함 / 이모티콘 화면은 왼쪽 미리보기 + 오른쪽 설정
 - 게임 중 화면을 돌려도 남은 조각이 새 보관함으로 자동 재배치
 - 아이패드 설치도 동일: Safari > 공유 > 홈 화면에 추가
